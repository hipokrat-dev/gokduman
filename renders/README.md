# Office material and lighting study

`office-study.png` is a Blender Cycles still, not a screenshot of the live Three.js application. The editable source is `assets/office-study.blend`; reproduce it using `scripts/render_study.py`.

This study adds procedural walnut and plaster, beveled manufactured edges, detailed desk accessories, an articulated task lamp, book spines, a VR headset, printer, and stethoscope. Soft window fill and warm practical lights are rendered with AgX and denoising at 1600 × 1100.

The existing live GLB is intentionally separate. Procedural shader materials must be baked to texture maps, and mesh complexity and lighting optimized, before this scene can replace the web scene. This image is a visual review milestone, not proof of mobile runtime performance or final photorealism.

## Refined study

`office-refined.png` and `assets/office-refined.blend` are generated by `scripts/refine_study.py`, which reads the original `office-study.blend`. This iteration uses Poly Haven's CC0 Dark Wood scanned PBR maps, finer surface detail, book and keyboard markings, VR sensors and ventilation, printer rails and electronics, monitor cabling, and a woven rug. Source attribution is stored alongside the maps.

The refined image is also an offline Cycles render, not the live browser result. Neither the source Blender scene nor this still replaces the published Three.js room automatically.

## Reference compositions

The user's desktop and mobile reference images define two distinct arrangements. Reproduce the current previews in this order:

1. `render_study.py` → initial editable source.
2. `refine_study.py` → scanned wood and detailed devices.
3. `compose_reference.py` → one upper shelf on desktop; three shelves on mobile.
4. `polish_reference.py` → corrected text orientation, articulated lamp, mobile monitor scale and warm lighting.

Latest outputs: `office-reference-desktop-v2.png` and `office-reference-mobile-v2.png`. Matching `.blend` files are in `assets/`. Earlier generated intermediates are kept locally but excluded from version control. These are original modeled approximations of the supplied composition; they are not identical reproductions of the reference images, nor screenshots of the live site.
